# 神域·月影

一个使用 C++ 编写的 Windows 控制台文字冒险小游戏。

这是我在学习 C++ 过程中独立完成的一个小游戏项目，主要以控制台字符界面为基础，包含地图探索、键盘移动、物品收集、背包、剧情交互、战斗和本地存档等功能。

## 项目简介

《神域·月影》是一款偏文字冒险和地图探索的控制台小游戏。玩家可以在不同地图中移动，与场景中的物体或角色触发交互，收集道具，推进剧情，并通过存档功能保存当前进度。

项目整体使用纯 C++ 编写，运行在 Windows 控制台环境下。

## 主要功能

- 控制台字符地图显示
- 使用键盘进行角色移动
- 地图碰撞检测
- 场景物品与 NPC 交互
- 背包与物品管理
- 简单战斗系统
- 剧情事件触发
- 玩家状态记录，例如日期、精力、属性、位置等
- 本地文本文件存档与读档
- 背景音乐播放

## 实现亮点

- **多线程 BGM 播放**：创建独立 `std::thread` 运行背景音乐逻辑，通过 `mciSendString` 调用 Windows 多媒体接口循环播放本地音乐，使 BGM 播放不阻塞主线程中的游戏流程和键盘输入。
- **实时键盘输入**：使用 `_getch()` / `_kbhit()` 获取键盘输入，实现无需回车的角色移动和菜单操作。
- **控制台文字表现**：使用 `SetConsoleTextAttribute` 控制文字颜色，用不同颜色区分提示、剧情、战斗等内容，提升控制台界面的表现力。
- **字符地图与碰撞检测**：使用二维字符地图显示场景，并通过地图数据数组记录墙体、物品、NPC、门等位置，实现基础碰撞和交互判断。
- **地图传送路径计算**：使用 Floyd 最短路径算法预处理地图之间的距离，用于计算传送时的精力消耗。
- **本地存档读档**：通过文本文件保存玩家位置、日期、精力、属性、背包、地图状态和剧情变量等信息，实现游戏进度保存与恢复。
- **背包系统**：记录物品编号、数量和获得状态，支持物品查看、使用和数量变化。
- **动态文字效果**：通过 `Sleep()` 控制文字输出速度，模拟打字机式剧情文本显示效果。

## 编译与运行

### 使用 Dev-C++

可以直接使用 Dev-C++ 打开：

```text
神域·月影.dev
```

然后编译运行项目。

### 使用 MinGW g++

也可以在项目根目录下使用 MinGW 手动编译：

```powershell
g++ -std=c++14 mainx.cpp operate1.cpp operate2.cpp Data.cpp -lwinmm -o 神域·月影.exe
```

运行时请确保以下目录和可执行文件在同一工作目录下：

```text
BGM/
Datas/
神域·月影.exe
```

## 操作说明

游戏中主要通过键盘进行操作，常用按键包括：

```text
W / A / S / D  移动
B              打开背包
C              存档 / 读档
R              退出游戏
H              回家
T              传送
P              修炼相关功能
```

部分按键或选项会根据游戏进度解锁。

## 存档说明

游戏存档位于 `Datas/` 目录下，主要使用文本文件保存玩家进度。存档内容包括玩家位置、地图状态、背包物品、属性、日期和部分剧情变量等。

## 项目说明

这个项目是学习阶段完成的作品，代码结构还有不少可以继续优化的地方，例如模块划分、数据管理和剧情事件系统等。  
不过它完整实现了一个控制台小游戏的基本流程，也让我练习了 C++ 基础语法、文件读写、数组建模、控制台输入输出和简单游戏循环设计。
